# 🌐 Netzwerk-Konfiguration

## Ziel

Kommunikation zwischen Kali Linux und Metasploitable2 ermöglichen.

---

## Netzwerktyp

Verwendet wurde:

* Host-Only Adapter

---

## Vorteile

* Keine Verbindung ins Internet
* Isolierte Testumgebung
* Sicher für Pentesting-Übungen

---

## IP-Adressen

Beispiel:

* Kali Linux: 192.168.56.101
* Metasploitable2: 192.168.56.102

---

## Verbindungstest

Von Kali aus:

```bash
ping 192.168.56.102
```

---

## Ergebnis

Die Systeme können miteinander kommunizieren.
Das Netzwerk ist korrekt eingerichtet.
